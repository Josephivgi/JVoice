JVoice 0.4.0 adds Agent mode, an optional voice assistant that can do things on your computer instead of only typing what you say. Speech to text is still the default, and nothing changes until you turn Agent mode on.

**New**
- Agent mode: switch between Speech to text and Agent on Home, in Settings > Mode, or from the tray menu.
- In Agent mode, hold your shortcut and ask a question. JVoice answers out loud.
- Or give it a task, like "open Spotify" or "open Notepad and write a shopping list". JVoice looks at your screen and opens apps, websites and files, clicks, types, presses keys and scrolls for you.
- Ask it to write something, like "reply saying I'll be there at 5", and the text goes where your cursor was.
- It can run PowerShell commands for you. By default JVoice shows you each command, and any program or script file it wants to open, and only runs it if you say yes. Settings > Mode can allow them always or turn them off.
- A card above the taskbar shows what you said, what JVoice is saying and what it is doing.
- Replies are spoken with a Windows voice and start before the full answer is ready. Pick the voice and speed, or turn off Talk back, in Settings > Mode.
- Follow ups within 3 minutes remember the conversation, so "now turn it up" works.
- Press Esc to stop the agent or its voice. Pressing your shortcut again also interrupts it.
- Pick the agent model in Settings > Mode. Claude Haiku 5.5 is the default because it is the fastest. Agent mode uses your OpenRouter key like dictation does.
- Agent runs are saved in History, with what you asked and what JVoice did.
